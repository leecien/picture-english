# 單字練習：生活情境素材包 01

使用者確認採自然、寫實的生活情境，放在「單字練習」。**每張只安排六個單字，硬上限七個**。RPG 角色、美術與地圖仍沿用統一的簡單可愛風格。

本交件含六張生成的寫實圖片（含已確認的餐廳）、36 個單字目標、12 個小任務與人工點擊區域草稿。程式由 Claude 接入；這份素材 PR 尚未提供新的可玩模式。

## 四種應用，避免只剩點圖

1. **自由探索**：點物件即發音，顯示中文、單字與經確認的 KK；未命中目標不扣分。已找到物件加明確標記，顯示如「找到 2 / 6」。可重聽，首次發現獎勵只領一次。
2. **聽音找物**：先播單字，播完再作答。問題階段不顯示英文名稱、KK 或目標輪廓，選完才揭曉。播放失敗提供重試，不能用答案文字假裝聽力已完成。背景重複物件要限定範圍或接受合理答案。
3. **找物拼字**：依中文／任務要求找到物品，鏡頭聚焦後用字母塊或已教字母組合拼字；完整答案在提交後顯示。未教音標或拼讀規律的長字先作辨識，不強迫新手一次拼出 toothbrush。一般單字聽寫也可明確作為另一種任務，與無提示拼字分開標示。
4. **生活小任務**：每次找 2–3 個物件達成目的，使用 JSON 中的十二個 mission。例如「確認登機文件」找 passport + ticket；「洗手擦乾」找 soap + towel。物件成功後打勾、播放發音，再完成任務；一次只要求目前場景六個詞，不額外塞入一批新詞。

每次可先玩 2–3 個目標的小輪，再繼續同張圖。不要強迫所有人將六詞各做四遍。探索曾看過答案不代表獨立作答；輔助成功與獨立成功分開。當題可修正，正式 KK 複習仍依新手村通關後安排。

後續可接自然句子，例如餐廳「I'd like a glass of water.」、機場「Where is my passport?」。這批的六詞上限先按物件詞彙計，句子不增加額外考核詞彙；句子題庫、配音和答案必須另外審查後接入。

## 接入資料

入口為 `scenes.draft.json`，圖片路徑相對儲存庫根目錄。每個 scene 的 `targets` 恰好六筆，包含英文、中文、優先序及正規化多邊形；每個任務只引用該圖已有目標。

- 座標原點左上，x/y 為 0–1，依圖片實際縮放和平移換算。
- 同一物件的正常輪廓可能重疊其他物件，按 `priority` 由高到低測試。例如筆先於筆記本、毯子先於床、湯匙先於餐盤。
- 多邊形是人工目測草稿，**還沒有實機點擊驗收**。請先疊圖檢查，再驗證觸控命中；不能以 JSON 可解析當作遊戲能玩。
- 不要把寬圖硬縮進手機而要求點細小牙刷、筆或湯匙。支援焦點放大／平移，觸控區至少 44 CSS px，擴大區域有衝突時顯示局部放大供選擇。拖動不能當成答案。
- 六個詞以外的圖片細節保持背景，不自動加入出題。餐廳原本十個目標已同步縮為六個；不要另讀取歷史清單擴充它。
- 臥室 blanket / pillow 會位於 bed 上，床目標優先使用露出的床架；辦公室 keyboard 指前景外接黑色鍵盤，notebook 指紙本；機場只指前景座位。
- 圖中的 milk 以情境與乳白色瓶裝液體表達，沒有商標文字；若使用者無法辨認，先提供教學示範，不直接判錯。ticket 先作生活口語「機票」，後續可在旅遊課教 boarding pass 的精確用法，不在本輪偷偷增加第七個考核詞。

## 單字與音訊

資料依本分支的 `data/words.json` 精確比對：35 個不同詞中，8 個已有題庫項目，**27 個需要補正式詞條與發音素材**。`pronunciation.wordBankMatch` 表示是否命中；找到的 KK 與現有音檔路徑僅沿用原資料，仍需教學檢查。

- 尚無題庫項目時 KK 為 null，不猜測，也不把字母名稱當成音素發音。
- 一般整字可使用裝置美式英文朗讀作暫時替代；這不等於獨立 KK 音素音檔，不能挪去做 KK 單音示範。
- 音檔存在才引用；與現有發音控制共用播放／停止，不疊加多個聲音。
- 本交件沒有修改主題庫。Claude 補詞條時保留既有 ID、`pm-*` 存檔與卡冊資料形狀；跨場景同詞共用紀錄，不能清掉舊卡重建。

## 驗收清單

- 六張圖各六個目標；任務引用都有效，背景不擴充新詞。
- 390px 寬手機可讀、能平移放大、各目標可點、拖動不誤送答案。
- 點擊必須實際發音；整字播放一次只一段，可重聽；播放失敗能重試。
- 聽音題先播後答，作答前不以標籤或英文選項透露目標。
- 拼字字塊可加入、移回，發音按鈕不攔截排序；判分後文字保持可讀。
- 沒有閃現記憶、蓋牌或翻找卡片模式；混合出題也不能抽回來。
- 先接超市六詞作完整流程測試，通過後再套用其餘場景；原存檔與單字卡可繼續使用。
