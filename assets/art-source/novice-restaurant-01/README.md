## 接圖注意

1. 以固定 512×512 網格切出來源。保留原圖；不要把這兩張圖直接當成現有的 96×96 走路精靈圖。
2. 比較 48px 實際顯示的輪廓、頭身比例、腳底基準線及不同地面上的可讀性。全套角色一起檢查，避免玩家和 NPC 再次出現不同畫風。
3. PNG 有透明通道，邊緣含半透明像素。請檢查淺色、深色及草地上的實際合成效果；若有色暈或邊緣問題，回報修圖，勿把原圖直接當作已驗收素材。
4. 目前只有正面待機，缺少背面、側面及動作。這批可先做對話頭像與戰鬥靜態圖；地圖移動沿用同風格占位，等四方向動畫補齊後整套換圖。
5. 音標、字母、血條、按鈕與答案提示由程式繪製；不烘焙進圖片。評量題作答前不能因素材檔名、替代文字或點擊提示洩漏答案。

## 餐廳找物：讓圖片成為遊戲場景

使用者要求：一張生活情境圖中有多個可互動物件，選出物件後練習它的單字，而非每張卡片只有一個孤立圖示。

第一輪先做五個容易分辨的目標：cup、plate、bread、chair、table；第二輪加 menu、fork、spoon、bowl、bottle。難度必須依已教的字母／音標控制，不因物件畫出來就要求新手拼完整長字。

### 探索教學

- 點物件：突出輪廓，播放單字。可重聽，並由程式顯示名稱、中文與 KK。
- 點杯子 → 聽 cup → 以已教的 c / u / p 字塊組字 → 成功後顯示完整單字與 KK、播放整字。
- 多次點同一物件可重聽，不重複領取首次獎勵。

### 任務考驗

- 聽音找物：先播放單字，音檔播放完才開放作答；目標不先顯示名稱或 KK。
- 找物拼字：給中文／情境要求，找到物件後拼字；提示與正確答案在提交之後顯示。不要在無提示測驗中預播整字答案。
- 答錯時當題可示範與修正，輔助後的成功與獨立答對分開記錄；正式複習仍安排在新手村通關後。
- 進階任務可從 cup 延伸到「I'd like a cup of tea.」，再到服務生點餐對話。句子排序必須使用實際有解且文法正確的字塊，不能只是看物件猜任意句子。
- 同一內容也能提供開車模式的聆聽／跟讀練習，共用學習紀錄；開車時不要求看圖找物或觸控。

### 點擊區域與手機版

JSON 是人工依原圖估計的多邊形，座標 x/y 均為 0–1，原點在左上。先測高 priority 的物件，再測桌子；點餐盤不能被桌子先攔截。圖上的裝飾餐盤圖案不列為第二個 plate 目標。

不要把 1536px 寬的圖硬縮成手機上無法點的細小物件。支援局部放大／平移或任務聚焦鏡頭，點擊區至少 44 CSS px；可加外擴範圍，但擴大後不能無法區分叉子、餐盤與湯匙。平移手勢與點擊分開處理，避免拖圖就提交答案。既有滿版 RPG 中開啟這個店內場景，結束回到原位置。
