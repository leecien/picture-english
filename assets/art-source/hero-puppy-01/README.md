## 程式端接圖工作
1. 逐格檢查角色及透明邊緣，不要假設生成圖已精準等距；若有多餘邊緣或裁切需修圖。
2. 統一人物大小、腳底定位與每格留白，再輸出每格 96×96 的透明 PNG。
3. 列順序：下、左、右、上；走路 4 欄、待機 2 欄。主角輸出 384×384 / 192×384；小狗同規格。
4. 預覽走路循環，確認左右腳交替與避免角色抖動。來源圖可能有相似重複姿勢，需要補畫或調整。
5. 主角左右朝向的法杖與背包側別需人工核對；不應在轉向時瞬移換手。
6. manifest 主角使用 hero-walk / hero-idle；怪物可暫保留 mob-muffin-walk / mob-muffin-idle 素材 ID，但顯示名稱改成小狗。
7. 本批只有走路與待機，攻擊、施法、受擊、倒地尚未提供，戰鬥開發繼續使用占位動作。
8. 請把角色和怪物各自對齊，勿套用相同外觀大小，確認手機比例。
