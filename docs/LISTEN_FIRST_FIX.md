# 聽音與流程修復（listen-first-01）

基於 Claude 開發版本 7874de2，使用獨立分支修復，未修改正式 main。

本批完成：

- KK 母音／子音題統一為先聽示範單字、再選含有的音；題幹與播放標籤不再露出單字。
- KK 重音題不先顯示圖片、拼字或帶重音標記的完整答案。
- 原 read 相容入口暫使用聽音選音標，不再混入看完整音標選單字；圖片組音標尚需另行實作。
- 課程與戰鬥播音期間隱藏選項，播完才提供可作答選項。播放失敗可手動重試，KK 不退回洩漏答案的文字模式。
- 課程與戰鬥題目共用可取消的播放等待；重播暫停倒數，保留剩餘秒數，不重置成完整作答時間。
- KK 錯答不立即標出或朗讀正解；需主動查看輔助示範。原本錯答紀錄保留，輔助完成不算獨立掌握。
- 課程音訊重播不會重新開放已判分的答案，避免重複寫入紀錄。
- 成功回饋時切背景也會暫停下一題；回來按「準備好了」才繼續。查看詞句發音時也不自動跳下一題。
- 達到單元八題上限但未達標時保留未完成狀態，下次可重新學該單元；不再無條件通過。
- 既有存檔鍵、模式、發音入口及非 KK 情境的文字備援保持相容。

測試：既有七組加 tests/listen-flow.cjs。新測試對錄音事件作可控延遲，涵蓋播音前答案不可見、重播保留時間、明暗外觀下錯答不自動揭曉、成功後切背景與零答對不通過。語音／麥克風真機品質仍需人工驗收。

本批尚未交付完整 41 音課程、獨立怪物原野、至少 30 題的新手村魔王與新手村取得旅伴；不得因這批修復標成全部功能完成。

預覽：嘗試建立獨立 GitHub Pages 儲存庫時，GitHub 整合回覆 `Resource not accessible by integration (createRepository)`。未修改正式 Pages 設定或覆蓋 main。

## 字母與音標的橋接教學

新增 `phonics.js` 六小節：字母名字與實際發音、短母音、字尾 e、sh/ch/ph/th、相同拼字的不同讀法、聲音組合。以現有題庫的 cat、cake、fish、tree、moon、book 等例字音檔示範，沒有用 TTS 朗讀單一音標，也不假設字母與 KK 一對一。

第一次找母音老師先進此段，每節可休息；`pm-rpg-v1.kk.spellingIntroStep` 保存讀到哪裡，`spellingIntroSeen` 只表示看過導讀，不等於母音課過關。選單的「字母與發音」可隨時重新開啟。尚非完整 A–Z 拼讀規則表或完整 41 音課程。

`tests/phonics.cjs` 驗證例字存在、音標對照、例字錄音播放、初次入口、中斷重載接續與選單重看；完整故事與原有 RPG 回歸另行測試。
