# RO 風格改版：分階段計畫與美術清單

目標：讓玩起來像《仙境傳說 RO》，但美術全部原創、走可愛奇幻路線。具體包括俯視角場景、點地面走路、角色動畫、向 NPC 接任務、在地圖上看得到怪物、打怪和掉落，並支援手機。英文學習成果要繼續寫回原有的卡冊、成就和學習紀錄。

分工：Claude 負責程式和測試；ChatGPT 負責美術素材和驗收建議；使用者確認方向和素材。所有工作都在開發分支上做，透過 Pull Request 合併，不直接修改 main。

## 相容契約（每一階段都要遵守）

- `pm-progress`、`pm-cards`、`pm-sents`、`pm-days`、`pm-log`、`pm-sound`、`pm-best-*` 的鍵名和資料形狀一律不改。
- `pm-rpg-v1` 原有欄位（version、map、positions、cleared、chests）保留原本的意義，新功能只新增欄位：
  - `world`：新場景中每張地圖的位置（第一階段）
  - `hero`：HP、MP、背包、裝備（第二階段）
  - `kk`：新手村進度（第四階段）
- 英文答題一律透過原有的 `record`、`addXP`、`award` 和 `pm-log` 寫入，讓卡冊、成就和紀錄自動累積。
- 沒有正式素材時，用程式畫的可愛占位圖。素材到位後只要填入 `assets/manifest.json` 就能替換，不需要改程式。

## 分階段計畫

### 第一階段：場景引擎（本 PR）

- 新增 `world.js`，用 Canvas 畫俯視角場景，每格 32 CSS px；地圖大小 24×16 格，鏡頭跟著角色移動。
- 點地面或觸控會走到目標位置，路徑計算支援八方向且不切角。點 NPC 或寶箱會先走到旁邊，再對話或開啟。鍵盤方向鍵、WASD 和 E 仍可使用。
- 角色有四個方向的走路和待機動畫。NPC 依地圖分成貓、兔、蛙、狐、熊五種造型，頭上有名牌和「!」任務標記。
- 每張地圖有 5 到 6 隻原創怪物，在出生點附近遊蕩，並顯示名稱和等級。
- 五張地圖各有不同版面（市場攤位、森林、湖泊、車站鐵道、小鎮房屋）；地形、建築和裝飾都依主題配色。
- 新增素材接口：`assets/manifest.json` 加入 `sprites` 和 `tiles` 區塊。圖檔載入成功就用圖，失敗或留空就用程式畫的占位圖。
- 首頁上方加入「冒險地圖」和「開車模式」快捷入口。
- 原有任務、寶箱、解鎖規則和存檔全部保留；位置另存在 `pm-rpg-v1.world`。

### 第二階段：HP／MP 與 RO 式戰鬥

- 常駐狀態欄顯示 HP、MP、等級頭像和背包按鈕，手機上固定在地圖上緣。
- 點怪物後，角色會自動走過去並持續普攻；普攻不耗 MP。畫面上會跳出傷害數字和受擊閃光，HP 歸零的怪物會播放消失動畫，一段時間後重生。
- 怪物分成主動攻擊和被動攻擊兩種；超出追擊範圍就會放棄追擊。
- 打倒怪物會掉落主題道具，以及小紅莓（回復 HP）和藍露珠（回復 MP）；點擊掉落物即可撿起。
- 恢復機制：
  - 補給：背包道具和 NPC 商店（用掉落物交換）。
  - 休息：按「坐下」後慢慢回復，移動或受到攻擊就會中斷。
  - 倒地：送回地圖出生點並恢復一半 HP 和 MP，不扣學習 XP 和卡片。
- 狀態存在 `pm-rpg-v1.hero`，重新整理後保留。

### 第三階段：英文技能

- 技能列預計有四格：
  - Word Strike：單字題，耗 MP 10，造成 2 倍傷害。
  - Sentence Burst：句子題，耗 MP 20，造成範圍傷害。
  - Listen Heal：聽音選字，耗 MP 15，回復 HP。
  - Element Combo：以主題元素加成，第二批再做。
- 施放時跳出答題面板，期間所有怪物暫停攻擊和移動。答對就施放強化攻擊；答錯會扣 MP，但不造成傷害，也不受懲罰。
- 題目從原有題庫抽取（依地圖主題和程度）。答對會透過 `record` 增加卡片和成就、增加 P.w／P.s 與 XP，並寫入 `pm-log`（新增 `m:'battle'` 類型，原本的紀錄頁也能看到）。
- 加入防刷保護：同一題在短時間內答對不會重複增加 XP，但仍會更新卡片紀錄。

### 第四階段：KK 新手村

- 新增 `kk` 地圖，永遠開放且不擋住原有的五張地圖解鎖。新玩家預設從這裡開始，舊玩家則會看到入口分頁。
- 村裡有 4 位 NPC，分別教母音、子音、重音和整字發音。任務題型包括：
  - 聽音檔選出正確的 KK 音標（使用題庫的 `kk` 和 `audio`）。
  - 看 KK 音標選出單字。
  - 選出重音在第幾個音節（解析音標裡的 `ˋ`）。
  - 母音配對：找出含有相同母音的單字。
- 新手村的怪物是「音節泡泡」，打倒後會掉落音標貼紙。
- 獨立的音標發音（每個 KK 符號一個音檔）目前題庫沒有，列在下面的素材需求。沒有音檔時，該題型改用「示範單字」發音代替，不會用 TTS 唸單一音標造成錯誤示範。

### 第五階段：接圖與打磨

- 依下表把正式素材接上，並調整碰撞框和動畫節奏。
- 使用 390px 寬的手機實測：確認 60fps、觸控誤觸和電量。
- 加入背景音樂、戰鬥音效，以及無障礙設定（減少動態、文字大小）。

## 美術清單（由 ChatGPT 繪製，使用者確認後上傳）

共通規格：PNG、透明背景、原創可愛奇幻風格，不帶文字、品牌，也不使用現有遊戲或卡通角色。所有素材使用同一種線條粗細和光影方向（光源在左上）。圖片解析度為顯示大小的 2 倍，以支援高解析螢幕。精靈圖每一列代表一個方向，順序為下、左、右、上；每一欄是一格動畫。

|---|---|---|
| `assets/sprites/hero-walk.png` | 主角走路 | 每格 96×96，4 欄 × 4 列（4 個方向 × 4 格） |
| `assets/sprites/hero-idle.png` | 主角待機呼吸 | 96×96，2 欄 × 4 列 |
| `assets/sprites/hero-attack.png` | 普攻（揮杖） | 96×96，3 欄 × 4 列 |

### C. 地圖圖塊（每張地圖一組）

`assets/tiles/<map>.png`：每格 64×64，依序為草地 ×2、小路、水面、水岸、樹、灌木、岩石、花、柵欄，以及建築左上、中、右上、左下、中、右下。
另外需要 `assets/tiles/props.png`：寶箱（關閉、打開）、路牌、傳送門 ×4 格動畫和點擊目標標記。

### D. 道具與 UI（第二、三階段）

- 道具圖示 64×64：小紅莓（HP）、藍露珠（MP），以及每張地圖 2 種掉落物（共 12 種）、音標貼紙。
- 技能圖示 96×96：Word Strike、Sentence Burst、Listen Heal、Element Combo。
- 特效精靈圖：打擊火花、五種元素的技能特效、回復光、升級光，每格 128×128，各 6 格。
- 狀態欄外框與 HP／MP 條（可伸縮的九宮格）、對話框外框。

### E. 音效與發音（使用者另行準備或用工具產生）

- 戰鬥音效：普攻、命中、怪物消失、撿取、回復、施放、倒地。可沿用 manifest 的 `hit`、`combo` 空位，並新增其他空位。
- 地圖背景音樂 ×6（含新手村），30 到 60 秒循環。
- **KK 獨立音標發音**：每個 KK 符號一個 mp3，放在 `assets/voice/kk/`，檔名例如 `i.mp3`、`ɪ.mp3` 改用 ASCII 名稱（`i-long.mp3`、`i-short.mp3`），對照表由 Claude 在第四階段提供。目前題庫沒有這批音檔。

## 驗收方式

每個階段都有 Playwright 自動測試（`tests/`），涵蓋舊存檔保留、390px 手機寬度、點擊走路與碰撞、任務共用紀錄、解鎖和重新整理後保留存檔，並使用截圖檢查畫面。麥克風、真實裝置語音和觸控手感需要人工試玩。
