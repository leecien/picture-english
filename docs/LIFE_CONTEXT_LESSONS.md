# 情境與句子帶入單字

入口：RPG選單 → 生活情境學英語。12個場景各有6組情境／英文句子／中文，共72組（71個不同重點字）。資料在data/life-contexts.json，與原照片的目標詞逐筆對應。

先呈現角色在生活中的需求，再用一句話帶入重點字。整句可播放，字可點擊查義與發音，也有獨立整字播放鍵。圖片自動聚焦相關物件，作為理解情境的輔助；點圖片不作答、不扣分。句子練習需聽完才啟用選項，以中文句意及英文空格練習使用單字。答錯不重複記錯，重試成功與首答正確分開記錄；只有首答正確透過既有Learn/卡冊/XP流程記錄。

舊探索／聽音找物／找物拼字／點物件完成任務的介面和執行路徑已移除。舊連結的mode參數會導向新情境故事；原pm-life-v1的found/res/missions保持相容，不清除舊進度。原照片及polygon保留給鏡頭聚焦與拖曳縮放，已非過關命中區。

聲音使用整句裝置朗讀，原有單字音檔可繼續使用；沒有新增真人句子錄音。正式單字庫仍為3000詞，不把72句或重複phone灌成新詞。

tests/life.cjs現在執行新的life-context.cjs：實際390px瀏覽器走完12場景72句，驗證只有兩個新模式、舊入口轉向、先播後選、空格不露字、錯誤／重試不刷XP、首答正確進卡冊。platform存檔及worker契約另測，web建置包含新教材。
