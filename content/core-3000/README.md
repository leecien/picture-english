# 3,000 詞教材擴充與 1,000 詞圖片目標

本輪要求：至少 3,000 個單字、多個生活句子，並讓其中至少三分之一（1,000 個不同單字）可透過圖片學習。每張生活圖只教 5–7 詞，本批固定六詞。Claude 負責程式接入，ChatGPT 負責教材草稿、圖片與品質檢查。

**本 PR 是教材與圖片來源交件，尚未達成完整可玩目標。** 不更換目前題庫，不修改遊戲程式或 `pm-*` 存檔。不能把 3,000 筆候選詞或 1,000 筆生產清單標示成已完成的教學功能。

來源數量不等於教學驗收數量。每個詞只有在圖中可辨認、有合理點擊範圍、可播放整字並完成對應練習後，才計入「完成的看圖學單字」。

## 檔案

- `words-3000.draft.json`：3,000 個唯一詞條、繁體中文釋義草稿、來源、詞形、現有 KK／錄音引用及圖片來源引用。
- `words-3000-review.csv`：便於試算表校對的詞表。
- `word-forms.draft.json`：詞形到原形的別名，不增加 3,000 的計數。支援後續句子點字查詢。
- `sentences-authored.tsv`：180 句原創生活例句及中文、主題、重點詞；詞形以 JSON 版本的正規化詞 ID 為準。
- `sentences-222.draft.json`：原有 42 句與新增 180 句，附可追溯原始資料及重點詞 ID。
- `image-1000.production-plan.json`：1,000 詞圖片生產候選佇列，明確區分已有互動場景、原圖待接入、待視覺校對候選。**不是 1,000 個已完成圖片單字。**
- `images/`：六張新生活圖片，以及 `scenes-batch-02.draft.json` 的六詞與點擊範圍草稿。
- `sources/`：資料來源、處理方法、授權與人工修訂清單。
- `validate.py`：內容契約檢查；不代替英文教學校對與手機操作驗收。

## 3,000 詞的順序與審核

詞表保留原有 80 詞、已有圖片詞、新句重點詞、本批圖片詞，再依來源詞頻補足。來源以 ECDICT 的英中詞條為基底，繁簡轉換採臺灣用語，常見多義詞另作部分人工修訂。完整來源與授權見 `sources/PROVENANCE.md`。

`editorialBand` 只是每千詞一批的編輯批次，**不是 CEFR 或 TOEIC 分級，也不是固定教學順序**。KK 新手村仍按發音與拼讀的先備關係教學。之後由教材校對把詞分到生活、旅行、工作等主題，再按音標／拼讀依賴、常用義、成人情境與句子難度安排課程。

每個新詞至少要校對：臺灣用語的常用義、詞性、多義詞在該情境的意思、美式發音／KK、錄音、例句與題目答案。尚未校對的內容不直接灌進現有看圖選字，避免所有沒圖的新字都顯示相同占位符。

來源詞典音標主要為英式記號，放在 `phoneticSource` 留作資料校對；**沒有轉寫成 KK**。原有 80 詞沿用既有 KK 與錄音。新詞沒有核對好的 KK 就保留 null，不猜、不把英式音標冠上 KK。一般整字可先用裝置美式朗讀，需在 UI 說明，且不能代替獨立音素示範。

## 新增 180 句的安排

十八個主題各十句：自我介紹、家庭、居家、飲食、購物、旅行、交通、飯店、辦公室、學習、健康、天氣、休閒、問路、科技、計畫、感受、處理問題。這些是完整例句草稿，不是拿一個模板換名詞湊數。

句子重點詞都連回 3,000 詞表；動詞變化連回原形。點句子裡已顯示的單字應能查字與聽整字，整句另設喇叭。新增例句還沒有設計填空空格與合理干擾項，不能由程式隨機刪字就宣稱完成可判分教材。

## 1,000 詞圖片生產規則

- 計不同詞，不計圖片張數、出現次數或同字的多種詞形。
- 每張 5–7 詞；若全無重複，1,000 詞約需 143–200 張圖，六詞一張約需 167 張。重複使用單字會增加實際所需張數。
- 候選佇列先提名名詞，但「名詞」不等於能看圖認出。抽象概念、多義詞、集合名詞及近義詞須人工挑情境；不能自動把每六個名詞拼成一張生活圖。
- 冰箱、餐具、衣物、交通、家電、工作用品、自然等可見物件先做。動作與形容詞之後用能清楚判斷的場景設計，避免只有照片卻無法判答。
- 不將同一物件同時計成一組近義詞的完成量。像 mug、cup、glass 要有足夠清楚的不同視覺與用法；本批 rug、scooter 使用精確對應名稱。
- 圖片文字、商標、音標或答案不可預先顯示；聽力題仍先聽後答。探索、聽音找物、拼字與生活小任務沿用現有玩法，不加蓋牌模式。
- 原圖進來源資料夾；Claude 壓成網頁格式、按場景延遲載入。不要一次下載所有原圖或為新字清除原存檔。

## Claude 接入順序

1. 先審第一批詞義與發音，接句子點字查詢，讓 almost 等原題庫以外的詞可查；維持排序字塊與發音控制獨立。
2. 接入本批六張圖，完成每圖六詞、拖曳縮放、可重聽、拼字移入移回及原位置返回的手機檢查。
3. 按已校對狀態逐批開放詞條；文字／聽力可用與看圖可用分開判斷。無圖詞不放進需要圖片判斷的題型。
4. 每批實際報告：可玩單字、可玩句子、不同圖片詞覆蓋、缺 KK、缺錄音、待校對數。到 3,000／1,000 時仍須以功能驗收，不只數 JSON 行數。
